# Attention quality engine
Based on Tim Wu's historical attention-market analysis, not an official Google policy.
Test headline-delivery gap, intrusive ad placement, interruption before answer, ad/content confusion, navigational friction, task completion and returning audience.
Signals: successful task completion (qualitative/user test), scroll behavior interpreted cautiously, voluntary return rate, direct visits, bounce/engagement in context.
Do not reward time-on-page in isolation. A one-minute answer to a one-minute question can be excellent.
Use NEEDS_DATA where behavioral metrics or actual layout are unavailable.
