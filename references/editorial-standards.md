# Editorial standards
Choose structure by task, not a universal SEO template:
- investigative: finding -> evidence -> mechanism -> challenge -> implications
- business/finance: thesis -> operating facts -> unit economics -> scenarios -> valuation/risk
- tutorial: prerequisites -> steps -> verification -> troubleshooting
- comparison: criteria -> evidence -> trade-offs -> decision
- commentary: event -> significance -> causal mechanism -> counterargument -> judgment
Keep claims proportionate to evidence. No manufactured certainty, fake first-person experience, redundant endings or inflated headlines.
Editorial pass: logical flow, precise nouns, time context, denominator clarity, factual consistency, readability, navigation, accessible visuals.
