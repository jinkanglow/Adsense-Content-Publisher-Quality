# Evidence engine
Material claims: numbers, dates, named entities, legal/policy assertions, comparisons, causal conclusions, predictions presented as facts.
For each claim store `claim_id`, `exact_text`, `type`, `source_url_or_document`, `source_date`, `accessed_at`, `primary_or_secondary`, `support_excerpt_or_locator`, `verification` (CONFIRMED/PARTIAL/CONTRADICTED/UNVERIFIED), `scope`, `confidence`, `fix`.
Prefer primary regulatory documents, filings, datasets and direct statements; triangulate when a claim is contested. Distinguish data publication date from event date.
Never treat a source's mere existence as proof. Check whether its actual content supports the exact claim, magnitude, population and timeframe.
Material contradiction or fabricated citation => hard blocker. Unverified material claim => revise or clearly qualify; never silently fill gaps.
Do not cite user-provided books as proving current AdSense policies.
