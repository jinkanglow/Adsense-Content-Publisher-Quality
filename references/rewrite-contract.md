# Rewrite output contract
Return in this order unless user specifies otherwise:
A. Repaired content — COMPLETE, copy-ready text; preserve the original language and headings as appropriate. Do not replace with outline or advice.
B. Editorial change log — original issue, action taken, why, evidence status.
C. Unresolved evidence — claim, required source/data, risk if published.
D. Post-edit gates — factual, reasoning, originality, reader value, policy and SEO, each PASS / REVIEW / FAIL / NOT_VERIFIED. Editorial score optional; never claim AdSense approval probability.
For bulk pages: supply page-by-page full replacements if within context budget; otherwise prioritized concrete patches with precise location and acceptance tests, and disclose pages not yet revised.
For requests explicitly asking only for final prose, omit B–D from user-facing response but still perform checks internally.
