# SEO and UX audit (separate from AdSense approval)
Inspect indexability, canonical signals, sitemap/robots when relevant, titles and snippets, navigation, working links, accessibility, mobile layout, speed and layout stability.
Distinguish technical checks from speculative ranking advice. Schema must match visible page content.
Check ad interference, deceptive buttons, obscured content and content-to-ad balance against applicable policy.
Report observed issues with URL, device, reproduction steps and severity; don't infer speed from prose alone.
