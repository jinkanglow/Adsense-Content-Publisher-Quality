# Seven-book integrated editorial operating model
**Economic mechanism (previous four books):** Wu *The Attention Merchants* -> audience attention incentives; Srnicek *Platform Capitalism* -> platform mediation and data; Giblin/Doctorow *Chokepoint Capitalism* -> bottlenecks and exit options; Wu *The Age of Extraction* -> distribution of created versus captured value.
**Editorial execution (new three books):** Borel *The Chicago Guide to Fact-Checking* -> independently reviewable claim evidence; Norton *Developmental Editing* -> argument architecture and manuscript revision; Land *Content Audits and Inventories* -> full-site inventory, criteria, pilot, action register and ongoing governance.

For a single article: extract claims -> verify -> diagnose thesis/structure -> rewrite -> extract claims again -> quality gate -> deliver publish-ready draft plus unresolved facts.
For a website: inventory -> sample/pilot -> qualitative and quantitative audit -> prioritize -> produce exact page patches -> validate site navigation/links/ads -> govern updates.
For business strategy: assess attention bargain, channel dependency, bargaining power and net value captured using actual data.

These books provide analysis and editing methods, not official AdSense rules. Apply official Google publisher policies separately. No book implies guaranteed approval, numeric traffic thresholds or automatic content quality score.
