# Editorial rubric and release gates
Weights (internal design, NOT Google approval probabilities):
- Accuracy/evidence 25
- Originality/information gain 20
- Causal reasoning 20
- Reader task completion 15
- Editorial clarity/density 10
- Search intent/organization 10
Score each 0–100 with written evidence, weighted total /100.
90+ target for strong editorial output; this is configurable, not a Google threshold.
Hard block: demonstrably false material claim, invented citation/test/credential, confirmed serious policy violation, or unsupported claim presented as certain where central to the thesis.
Decisions: PUBLISH if all gates pass and quality target reached; REVISE if fixable; REJECT if foundationally misleading; INSUFFICIENT_EVIDENCE if essential verification unavailable.
Policy result is separately PASS / FAIL / NEEDS_REVIEW / NOT_VERIFIED. Never average it with editorial score.
Independent critic must list strongest objections and verify fixes before release.
