# Comprehensive audit report
Deliver: (1) scope and limitations, (2) official policy matrix, (3) site navigation and broken URLs, (4) URL inventory with page-level findings, (5) claim/evidence ledger, (6) originality and task completion, (7) link graph, (8) indexing distinctions, (9) mobile UX and accessibility, (10) economics only when real data exists, (11) prioritized fixes with acceptance tests, (12) full revised copy when requested, (13) post-fix re-audit, (14) unresolved verification needs. Do not output unsupported approval probabilities.
