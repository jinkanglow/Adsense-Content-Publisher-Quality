# Evidence-backed audit findings
Each finding must contain URL, timestamp, fetch method, observation, policy source or editorial basis, confidence, severity, and verification status. Never infer actual indexing from crawlability. Never assert 100% originality without sufficient evidence. Use NOT_VERIFIED for unobserved claims. Count discovered, fetched, failed and sampled URLs. BLOCKER only for verified serious issues, not arbitrary SEO preferences.
